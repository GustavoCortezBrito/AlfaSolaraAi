# ☀️ Logo Alfa Solar - Design e Conceito

## 🎨 Conceito da Logo

A logo **Alfa Solar** foi desenvolvida para representar a expansão da Alfa Esquadrias para o mercado de energia solar, mantendo a identidade visual da marca mãe enquanto adiciona elementos que comunicam sustentabilidade e energia renovável.

## 🏢 Elementos da Logo

### 1. Duplo "A" Metálico (Identidade Alfa)
```
✓ Mantém o símbolo icônico da Alfa Esquadrias
✓ Gradiente prateado/metálico (alumínio)
✓ Efeito 3D com sombra
✓ Representa solidez e qualidade
```

### 2. Sol Estilizado (Energia Solar)
```
☀️ Posicionado atrás do logo
☀️ Gradiente amarelo/laranja
☀️ Raios solares sutis
☀️ Representa a fonte de energia
```

### 3. Painel Solar Integrado (Tecnologia)
```
⚡ Linhas horizontais sobre o "A"
⚡ Células solares estilizadas
⚡ Gradiente azul/cyan
⚡ Representa a tecnologia fotovoltaica
```

### 4. Ícone de Energia (Modernidade)
```
⚡ Raio estilizado no canto
⚡ Cor azul/cyan
⚡ Efeito de brilho
⚡ Representa eletricidade e inovação
```

## 🚫 Uso Incorreto

### Não Fazer:
- ❌ Alterar proporções (esticar/comprimir)
- ❌ Mudar cores sem autorização
- ❌ Adicionar efeitos não aprovados
- ❌ Usar em fundos que prejudiquem legibilidade
- ❌ Remover elementos (sol, painel, etc)
- ❌ Rotacionar ou inclinar

### Fazer:
- ✅ Manter proporções originais
- ✅ Usar cores aprovadas
- ✅ Respeitar área de proteção
- ✅ Usar em fundos escuros ou claros apropriados
- ✅ Escalar proporcionalmente

## 🎓 Diretrizes de Uso

### Para Designers
1. Sempre usar arquivos originais
2. Não recriar a logo
3. Respeitar proporções
4. Usar cores exatas (códigos hex)
5. Manter área de proteção

### Para Marketing
1. Usar versão apropriada para cada mídia
2. Garantir legibilidade
3. Manter consistência
4. Aprovar materiais antes de publicar

### Para Desenvolvedores
1. Usar componente React quando possível
2. Otimizar SVG para web
3. Garantir acessibilidade
4. Testar em diferentes dispositivos
